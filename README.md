## 📂 Ejercicios

La carpeta [`conquer-js-ejercicios/`](./conquer-js-ejercicios/) contiene la página inicial y las nueve actividades. Cada ejercicio tiene su propio archivo HTML y su archivo JavaScript separado.

| # | Ejercicio | Práctica |
|---|---|---|
| 01 | Cambiador de color de fondo | Eventos y estilos del DOM |
| 02 | Contador de clics | Eventos y actualización del DOM |
| 03 | Lista dinámica | Creación y eliminación de elementos |
| 04 | Filtro de búsqueda en tiempo real | Eventos de entrada y filtrado |
| 05 | Calculadora sencilla | Operaciones y validación |
| 06 | Temporizador | Inicio, pausa y reinicio |
| 07 | Generador de contraseñas | Generación aleatoria y validación |
| 08 | Contador de palabras y caracteres | Actualización en tiempo real |
| 09 | Lista de tareas | Persistencia con LocalStorage |

## 📄 Cómo abrir

Abre [`conquer-js-ejercicios/index.html`](./conquer-js-ejercicios/index.html) en un navegador y selecciona una actividad desde el índice. No necesitas instalar paquetes.

## ✅ Estructura

```text
Proyecto-JS-TAREA/
├── conquer-js-ejercicios/
```

Los estilos compartidos están en `conquer-js-ejercicios/styles.css`. El código de cada ejercicio permanece en su propio archivo JavaScript.
